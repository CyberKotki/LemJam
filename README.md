# Spaw Point - LemJam Game

**Spaw Point** is a point-and-click game inspired by The Cyberiad by Stanisław Lem. The player takes on the role of a welder-constructor tasked with connecting various parts of a machine. The challenge lies in remembering where each joint is located and welding it "blindly." Points (represented as screws) are awarded based on the accuracy of each weld.
